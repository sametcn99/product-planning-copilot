# Source Planning Folders

Each project must be created under `src/<project-slug>/`.

Recommended file set for every project folder:

1. `00-project-brief.md`
2. `01-prd.md`
3. `02-roadmap.md`
4. `03-architecture-notes.md`
5. `04-task-breakdown.md`
6. `05-risks-and-decisions.md`

Use kebab-case folder names, for example:

- `inventory-optimization-platform`
- `local-ai-document-assistant`

You can copy the scaffold from `src/_project-template/` when starting a new project.
